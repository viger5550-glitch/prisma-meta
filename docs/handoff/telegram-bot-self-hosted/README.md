# Свой Telegram-бот: пакет для нового проекта

Этот набор — не код бота. Его нужно **скопировать в новый репозиторий** (или открыть рядом) и отдать **новому агенту**. В `prisma_meta` бота не реализовывать.

| Файл | Зачем |
|---|---|
| [SUMMARY.md](./SUMMARY.md) | Решения из обсуждения 2026-09-15 |
| [TZ.md](./TZ.md) | Требования, архитектура, миграция с LEADTEX |
| [PLAN.md](./PLAN.md) | Задачи фазы 1 |
| [AGENT-PROMPT.md](./AGENT-PROMPT.md) | Текст первым сообщением новому агенту |

Как завести проект:

1. Создай пустой репозиторий (например `productodel-bot`).
2. Открой его в Cursor новым чатом.
3. Вставь промпт из `AGENT-PROMPT.md`.
4. Приложи `TZ.md` и `PLAN.md` (скопируй файлы в новый репо в `docs/`).
5. До старта кода подготовь: тестовый бот в BotFather, свой Telegram id, выгрузку контактов из LEADTEX.
