Ты разрабатываешь отдельный Telegram-бот с нуля в этом репозитории. Сайт Prisma Meta — другой проект, сюда его не тащи.

## Задача фазы 1 (MVP)

Сделать своего бота на хостинге, который:

1. Принимает `/start`, сохраняет `telegram_id` / `chat_id` в свою БД (без дублей).
2. Умеет импортировать контакты из Excel/CSV выгрузки LEADTEX (обязательная колонка Telegram ID).
3. Даёт админу рассылку текстом по всем `active` контактам через тот же Bot API (`sendMessage` по `chat_id`).
4. Работает по webhook 24/7, секреты только в env.

Cursor — только разработка. Рассылки отправляет задеплоенный сервер, не сессия агента.

## Как устроен Telegram (не путать)

Telegram не отдаёт список всех, кто нажал Start. Список — только то, что мы сами записали или импортировали. Писать можно лишь тем, кто стартовал **этот** токен и не заблокировал бота. Один токен может висеть либо на LEADTEX, либо у нас, не на обоих сразу.

Миграция боевого бота (когда владелец даст токен и файл):

1. Выгрузка контактов из LEADTEX уже сохранена.
2. Наш бот проверен на тестовом токене.
3. Импорт файла в БД.
4. Отвязать токен в LEADTEX.
5. Подставить боевой токен, выставить webhook.
6. Проверить Start и тестовую рассылку.

Пока токена нет — реализуй на тестовом боте из BotFather.

## Стек (если владелец не скажет иначе)

- TypeScript, Node 20+
- grammY
- PostgreSQL (в локальной разработке допустим SQLite, но схема та же)
- webhook, не long polling в проде
- Railway: Procfile/`npm start`, `PUBLIC_BASE_URL`

## Поведение

Пользователь: `/start` — приветствие-заглушка, запись в `contacts`.

Админ (`ADMIN_TELEGRAM_IDS`): `/stats`, `/broadcast` с превью и подтверждением `ДА`, очередь с паузой из-за лимитов Telegram, учёт 403 Forbidden как `blocked`.

Не делать в MVP: LLM-агента, оплаты, копию воронки LEADTEX, админку на сайте Prisma, коммит `.env` и файлов выгрузки.

## Данные

`contacts`: telegram_id PK, chat_id, username, имена, source (`start` | `leadtex_import`), status (`active` | `blocked` | `deactivated`), timestamps, tags опционально.

`broadcasts` + `broadcast_receipts` для истории.

## Ограничения

- Не пиши эксплойты и не обходи блокировки Telegram.
- Не рассылай без подтверждения админа.
- Соблюдай лимит ~25 msg/s, обрабатывай 429.
