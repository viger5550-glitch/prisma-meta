# Навигация с лендингов

Пункты шапки дублируют карточки главной (`HOME_OFFERS`): **Кати на prod**, **AI AGENTS**, **STORY BOOK**, **AI AGENTS DEV**, **APPS DEV**. Логотип **PRISMA** ведёт на главную.

## Правило

На лендингах (`/challenge`, `/triz`, `/agents`, `/apps`, `/about`, `/meta/manifesto`, `/mentorship` и новые) **не** ставить `BackButton` и ссылку «← PRISMA». Возврат на главную — только через хедер.

Вложенные страницы вне каталога (например `/challenge/[slug]`) могут оставлять локальную ссылку «назад» к родительскому лендингу — это не переход на главную.
